# Contributing to ResourceHub

Thank you for considering contributing to **ResourceHub**! We welcome contributions from developers of all skill levels.

---

## Code of Conduct

We are committed to providing a welcoming and inclusive environment. Please treat all contributors with respect, professionalism, and empathy.

---

## How Can I Contribute?

### 1. Reporting Bugs
- Search existing issues to ensure the bug hasn't already been reported.
- Open a new issue with a clear title, reproduction steps, expected behavior, and actual behavior.

### 2. Suggesting Enhancements
- Open a new issue detailing the feature, why it is useful, and potential implementation approaches.

### 3. Pull Requests
- Fork the repository and create a new feature branch from `master`.
- Keep pull requests focused on a single feature or bugfix.
- Follow code style guidelines and ensure CI gates pass:
  ```bash
  npm run lint
  npm run typecheck
  ```

---

## Code Style & Commit Conventions

- Use **TypeScript** strict types. Avoid `any` types.
- Follow **Conventional Commits**:
  - `feat:` A new feature
  - `fix:` A bug fix
  - `docs:` Documentation changes
  - `refactor:` Code refactoring without behavior changes
  - `chore:` Build scripts or maintenance tasks

Thank you for helping make ResourceHub better!
